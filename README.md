# 🌐 GenAI Hub - Portal Informativo sobre Inteligencia Artificial Generativa

Sitio web moderno de página única (*Single Page Application*) desarrollado exclusivamente con **HTML5, CSS3 y JavaScript Vanilla**, con una estética profesional inspirada en el perfil de José Manuel Perdomo.

## 🚀 Características Principales
- **Conceptos Fundamentales**: Diferencias clave entre la IA Clásica/Discriminativa y la IA Generativa.
- **Modelos y Arquitecturas**: Transformers, Modelos de Difusión, Redes Antagónicas (GANs) y Modelos Multimodales.
- **Campos de Aplicación**: Filtros dinámicos en tiempo real (Desarrollo, Creatividad, Negocios, Ciencia).
- **Simulador Interactivo de Prompts**: Emulación de streaming de tokens, control de temperatura y copiado de respuestas.
- **Diseño Ergonómico**: Navegación interna con scroll suave y botones de demostración con notificaciones *toast* (sin navegación externa).

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica y accesible.
- **CSS3**: Variables CSS nativas, diseño responsivo y efectos visuales modernos.
- **JavaScript (ES6+)**: Lógica interactiva en cliente sin dependencias ni librerías externas.
- **GitHub Pages / Actions**: Despliegue continuo automatizado.

## 💻 Despliegue Local
Puedes abrir directamente el archivo `index.html` en tu navegador o iniciar el servidor local con:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 8080
```
Luego visita: `http://localhost:8080/`
